# ClearPic Local

PNG·JPG·WEBP 이미지에서 사용자가 권리를 가진 가시적 표시나 불필요한 영역을 로컬에서 정리하는 브라우저 앱입니다. 이미지 파일은 서버에 업로드되지 않습니다.

## 실행

```bash
cd /home/openq/code/food/deliverables/clearpic_local
chmod +x scripts/*.sh
./scripts/serve_supervised.sh 4180
```

브라우저에서 `http://127.0.0.1:4180`을 엽니다.

## 발급할 것

없습니다. API 키와 계정이 필요하지 않습니다. ZIP 생성 및 선택적 OCR 모듈을 CDN에서 받기 때문에 첫 실행에는 인터넷 연결이 필요합니다. 이미지 처리는 브라우저 메모리 안에서 이루어집니다.

## 사용 순서

1. 이미지를 끌어다 놓습니다.
2. Gemini 표시 자동 정리, 문구 찾기 또는 브러시로 마스크를 지정합니다.
3. 선택 영역 정리를 누르고 원본 비교로 결과를 확인합니다.
4. 크기·형식·품질을 선택하고 ZIP으로 내려받습니다.

## 주의

- 주변 픽셀을 이용한 로컬 채움 방식이므로 복잡한 배경에서는 수동 보정이 필요할 수 있습니다.
- Gemini 원본 이미지가 아닌 경우 자동 위치가 맞지 않을 수 있으므로 브러시를 사용하세요.
- SynthID 같은 비가시성 표식은 제거하거나 변경하지 않습니다.
- 본인이 권리를 보유하거나 정당한 이용 허락을 받은 이미지에만 사용하세요.
- 작업 내용은 메모리에 있으므로 창을 닫기 전에 결과를 내려받으세요.

## 감시기 복구 시험

```bash
./scripts/watchdog_selftest.sh
```

자식 서버를 강제 종료한 뒤 부모 감시기가 새 프로세스로 복구하고 HTTP 응답이 돌아오는지 검사합니다.
